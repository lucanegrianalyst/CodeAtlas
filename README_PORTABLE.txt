PYTHON PROJECT INTELLIGENCE
============================

VERSIONE PORTABLE

START:
    python project_intelligence.py

La cartella e' stata costruita come copia pulita
del motore Python Project Intelligence.

CONTENUTO:

- project_intelligence.py
- core/
- analyzers/
- output/

Sono stati esclusi:

- backup
- file di test
- vecchie versioni
- __pycache__
- log storici
- vecchi SITE_AUDIT
- vecchi report di sviluppo

OUTPUT:
La cartella output viene lasciata vuota.

Il programma deve poter essere copiato in qualsiasi
progetto Python e utilizzato come analizzatore.

Esempio:

C:\music_ai\python_project_intelligence

Il progetto analizzato deve essere il progetto
da cui viene avviato l'orchestratore secondo
la configurazione del programma.

NON CANCELLARE LA VERSIONE ORIGINALE FINCHE'
LA VERSIONE PORTABLE NON E' STATA TESTATA.
